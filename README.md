# Jengrac Education Foundation Website

Production-grade Next.js foundation for the Jengrac Education Foundation website, focused on Artificial Intelligence, Extended Reality, Spatial AI, immersive learning and South African human-capability systems.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Motion for React
- Lucide React
- Zod
- React Hook Form-ready architecture
- Vitest
- Playwright

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verification

```bash
npm run lint
npm run typecheck
npm run test
npm run test:e2e
```

## Content Integrity

No JEF impact statistics, partner names, project outcomes or institutional claims should be published until verified by JEF. Placeholder content is intentionally marked.
