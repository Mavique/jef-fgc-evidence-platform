# Animation Doctrine

Motion must explain relationships rather than decorate.

Use:

- Scroll reveals for chapter progression
- Word reveals for institutional statements
- Hover motion on images and actionable programme surfaces
- Slow marquee for partnership pathway scanning
- Reduced-motion fallbacks for all animated experiences

Do not use meaningless particles, animated blobs or excessive glow effects. GSAP is not included because the master brief specifies Motion for React unless a requirement cannot reasonably be met with Motion and browser capabilities.
