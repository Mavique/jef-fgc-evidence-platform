# Content Model

Initial local content is stored in `src/content/site.ts`.

Core models:

- Programmes: slug, name, status, audience, reach, purpose, image
- Impact records: title, value, classification, note
- Regions: name, state, x/y placement
- Partnership pathways: name and future route metadata

Future CMS collections should add:

- People and leadership
- Governance documents
- Project stories
- News and insights
- Partner profiles
- Verified impact records with source, date, geography and approval status
