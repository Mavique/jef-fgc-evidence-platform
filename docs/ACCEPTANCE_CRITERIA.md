# Acceptance Criteria

The website is acceptable when:

- It runs locally with `npm run dev`.
- The homepage communicates JEF as an African education transformation and capability institution.
- It includes AI, Extended Reality and Spatial AI in a serious educational context.
- All required primary routes exist.
- Unverified claims remain marked as placeholders.
- The design does not resemble a generic SaaS, NGO or online-learning template.
- Navigation works on desktop and mobile.
- Reduced-motion preference is respected.
- Linting, type checking and tests pass.
