# Accessibility Standard

The site must preserve:

- Semantic landmarks
- Keyboard-accessible navigation
- Visible focus states
- High contrast action surfaces
- Reduced-motion support through `prefers-reduced-motion`
- Responsive text sizing that does not overflow containers
- Informative alt text for meaningful imagery
- Empty alt text for decorative imagery

Before publishing, run keyboard checks across navigation, mobile menu, CTAs and forms.
